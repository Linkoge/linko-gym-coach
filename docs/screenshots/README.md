# Screenshot provenance

Only non-private public demonstration material is used here. Upload/results
screenshots show the local Stage 1 application. No user workout video is included.

- `upload.png`: upload interface, no workout imagery.
- `results.png`, `results-mobile.png`, `verification.png`, `skeleton-overlay.jpg`: weighted squat
  demonstration by **FitnessScape**, [Wikimedia source](https://commons.wikimedia.org/wiki/File:Squat_-_exercise_demonstration_video.webm),
  [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Changes: MP4
  conversion, pose annotation, selected still frames, presentation in the
  Linko results page. Original source: [Half Rack Workout](https://www.youtube.com/watch?v=0I6q9NqK9tM).

The screenshot files document behavior; they do not demonstrate validated
biomechanical accuracy or licensor endorsement. Private screenshot exports
belong only in ignored `data/` directories.
